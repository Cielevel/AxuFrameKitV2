# LiveUtil

Standalone Live Stream utility module.

## Description
This package provides UI and utility logic for live streaming integration, derived from the AxuFrameKit.Modules.LiveStream module but completely decoupled from the core framework.

## Installation
Add this folder to your Unity project's `Packages` folder or reference it via local path in `manifest.json`.

## Structure
- **Runtime**: Core logic and UI components.
- **Editor**: Inspector extensions and editor tools.
- **Samples~**: Usage examples.
