# Noise - 噪声生成工具

## 功能概述

噪声生成工具集，提供多种噪声算法和可视化方式，用于程序化内容生成。

## 主要特性

### 噪声算法
- **SimpleNoise**：基于哈希的值噪声
  - 支持 1D 和 2D 噪声
  - 可配置种子和频率
- **SubCellularGenerator**：子细胞噪声生成器
  - 基于 FastNoiseLite 库
  - 双层细胞噪声，支持大色块和细分结构

### 可视化工具
- **NoiseVisualizer**：Scene 视图 Gizmos 绘制
  - 绘制 1D 噪声曲线
  - 实时预览噪声变化
- **NoiseVisualizeQuad**：运行时网格可视化
  - 动态生成 Quad 网格
  - 将噪声值映射为颜色

### 参数配置
- 可调节的噪声参数（频率、振幅、种子等）
- 实时预览参数变化
- 支持纹理导出

## 使用场景

- 程序化地形生成
- 纹理生成
- 环境效果（云、雾、水面）
- 随机地图生成
- 视觉特效

## 依赖

- FastNoiseLite（用于细胞噪声）
