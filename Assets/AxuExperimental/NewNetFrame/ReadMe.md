# NewNetFrame - 网络通信框架

## 功能概述

一个类型安全、过程安全的网络通信框架，采用策略模式和构建器模式设计。

## 主要特性

### 多种通信方式
- **HTTP 短连接**：使用 UnityWebRequest 实现 GET/POST 请求
- **WebSocket 长连接**：使用 C# ClientWebSocket 实现双向通信

### 序列化支持
- **JSON 序列化**：基于 Unity JsonUtility
- **类型安全**：泛型接口确保请求/响应类型安全

### 核心接口
- `INetClient` - 网络客户端接口
- `ISerializer` - 序列化器接口
- `NetResult<T>` - 统一的结果包装类

### 错误处理
- **NetResult 模式**：避免异常抛出，提供清晰的错误处理
- **成功/失败分离**：明确区分成功和失败的处理路径
- **错误信息**：详细的错误描述和状态码

### 设计模式
- **策略模式**：可替换的通信策略和序列化策略
- **构建器模式**：链式调用配置请求参数

## 使用场景

- 与 RESTful API 通信
- 实时游戏服务器连接
- 需要类型安全的网络请求
- 复杂的网络请求配置

## 技术亮点

- 避免异常的性能开销
- 清晰的 API 设计
- 易于单元测试
