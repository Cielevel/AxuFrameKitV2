# OllamaModelCall - Ollama AI 模型集成

## 功能概述

与本地 Ollama AI 模型集成的工具集，支持 AI 辅助开发。

## 主要特性

### OllamaClient - API 客户端
- **本地服务连接**：连接本地 Ollama 服务（默认端口 11434）
- **协程调用**：使用 Unity 协程处理异步请求
- **简单接口**：简洁的 API 调用方式
- **响应回调**：通过 Action 回调返回 AI 响应

### OllamaScriptFillerWindow - 智能字段填充
- **AI 辅助开发**：利用 AI 分析脚本字段并自动匹配
- **组件自动绑定**：根据字段名智能匹配子对象的组件
- **语义匹配**：支持语义级别的名称匹配
  - 如 `btn_submit` 匹配 `SubmitButton`
  - 支持驼峰、下划线等多种命名风格
- **类型验证**：自动验证匹配的组件类型是否正确
- **多语言匹配**：支持中英文字段名匹配

## 使用场景

- 快速绑定 UI 组件
- 自动化脚本初始化
- 减少重复的手动拖拽工作
- AI 辅助的编辑器工具开发

## 前置要求

- 本地运行 Ollama 服务
- 下载相应的 AI 模型

## 技术亮点

- 将 AI 能力集成到 Unity 编辑器
- 语义理解和模糊匹配
- 提升开发效率的实用工具
