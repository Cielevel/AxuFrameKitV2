# SceneCurveDraw - 场景曲线绘制工具

## 功能概述

在 Unity Scene 视图中绘制和编辑贝塞尔曲线的工具，支持可视化路径设计。

## 主要特性

### PathController - 曲线路径控制器
- **贝塞尔曲线**：存储和管理贝塞尔曲线控制点
- **曲线计算**：提供曲线上的点计算方法
- **Gizmos 可视化**：在 Scene 视图中显示曲线

### 编辑器扩展
- **Scene 视图编辑**：在 Scene 视图中直接编辑曲线
- **可拖拽控制点**：使用 Handles 实现控制点拖拽
- **撤销支持**：完整的 Undo/Redo 支持
- **平滑曲线绘制**：使用 `Handles.DrawBezier` 绘制高质量曲线

### 控制点管理
- 动态添加/删除控制点
- 每个点包含位置和切线信息
- 支持曲线的实时预览

## 使用场景

- 游戏路径设计（敌人巡逻路线、摄像机轨道）
- 程序化动画路径
- 关卡设计辅助工具
- 可视化轨迹编辑

## 技术亮点

- 完整的 Scene 视图集成
- 流畅的编辑体验
- 标准的贝塞尔曲线算法
