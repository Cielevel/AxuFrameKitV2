# AxuIndie - Scene Jumper

场景收藏 / 分组 / 快速跳转的编辑器窗口（独立模块，无任何依赖）。

## 用途

- 收藏常用场景，一键快速打开
- 将场景按自定义分组管理
- 在编辑器窗口中浏览 Build Settings 内的场景与项目内全部场景

## 菜单路径

`AxuIndieModules/SceneJumper`

## EditorPrefs 键

- `SceneJumper_FavoriteScenes`：收藏的场景列表
- `SceneJumper_CustomGroups`：自定义场景分组数据

## 说明

嵌入式包（Embedded Package），位于 `Packages/` 下随项目分发。
