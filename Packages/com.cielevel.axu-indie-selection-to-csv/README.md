# AxuIndie - Selection To Csv

将 Project 窗口中选中的资源导出为 CSV 文件的独立编辑器工具。

## 使用

菜单入口：`AxuIndieModules/Selection To Csv`

打开窗口后，在 Project 窗口中选择需要导出的资源，点击导出即可生成 CSV。

## 包说明

本包为**嵌入式包**（Embedded Package），位于 `Packages/` 目录下，可直接编辑源码。模块完全独立，无外部依赖，仅包含 Editor 代码（`AxuIndieModules.SelectionToCsv` 程序集，Editor-only）。
