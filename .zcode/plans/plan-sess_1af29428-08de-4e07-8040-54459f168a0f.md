## 方案：新增独立窗口 ScriptableObjectCreatorWindow（通用 SO 资产创建）+ CreatorEntryAttribute

**前置结论**：工程内无此功能；参照 `CsvContainerCreatorWindow` 范式（UI Toolkit + AxuKitTheme、扫描→搜索→左列表右详情→创建后 Ping），剥离 CSV 专用耦合。

### 一、新增 `CreatorEntryAttribute`（用户追加需求，可选标签）
1. **新增 `Runtime/Common/CustomAttribute/CreatorEntryAttribute.cs`**（+ .meta，namespace `AxuFrameKit.Common.CustomAttribute`，与 InspectorTitle/InspectorIntro 同目录）
   - `[AttributeUsage(AttributeTargets.Class, AllowMultiple = false, Inherited = false)]`，单 string 参数 `EntryPath`
   - 语义（同 MenuItem/CreateAssetMenu 路径风格）：最后一段 = 面板显示名（替代类名），前序段 = 分组路径；`\"道具\"` → 顶级显示名；`\"配置/战斗/SkillData\"` → 分组 配置/战斗，显示名 SkillData；仅对 SO 子类生效（扫描侧只查 SO 子类，天然满足）
2. 窗口集成：左列表按 EntryPath 前序段构建可折叠分组树（Foldout），无 Attribute 的类型按类名显示在顶级"未分组"区（排最后）；搜索同时匹配显示名/类名/命名空间；详情面板增加一行"创建面板条目：分组路径 + 显示名"

### 二、新增独立窗口
3. **`Editor/Common/Window/ScriptableObjectCreatorWindow.cs`**（+ .meta，namespace `AxuFrameKit.Common.Editor.Window`）
   - 入口：`[MenuItem(\"AxuFrameKit/Asset/ScriptableObject Creator\")]`；右键入口 `Assets/Create/AxuFrameKit/ScriptableObject Creator`（validate + priority 100，选中文件夹作为创建初始目录）
   - 类型扫描（抽 internal static scanner，可测）：遍历程序集（跳 dynamic、try/catch），非抽象 class 且 `IsSubclassOf(typeof(ScriptableObject))`、非泛型定义；排除 `UnityEngine/UnityEditor/Unity/TMPro/Microsoft/System` 开头命名空间；支持\"仅框架类型\"（`IsSubclassOf(CustomScriptableObject)`）Toggle；读取 CreatorEntryAttribute 解析显示名+分组；按排序键排序
   - UI Toolkit（`CreateGUI`）：AxuKitTheme 三件套接入；工具栏 = 搜索框 + 仅框架类型 Toggle + 刷新 + 数量 badge；左栏 = 分组树类型列表（cs Script Icon + 显示名 + 命名空间短 badge，row.userData 存 Type）；右栏 = 头部（图标/显示名/定位脚本）+ InspectorTitle/InspectorIntro meta + 信息行（FullName/Assembly/条目路径）+ public 序列化字段预览 + 同类型已有资产列表（`t:{Name}` 查找、点击 Ping/Select）+ 创建按钮
   - 创建流程（对齐 CSV Creator）：初始目录 = Project 选中项所在目录（右键入口用选中文件夹）→ `SaveFilePanelInProject` 默认名 `{类型名}.asset` → `CreateInstance` → `AssetDatabase.CreateAsset` + `SaveAssets` → `Selection` + `PingObject` + 日志
4. **`Editor/Common/Window/ScriptableObjectCreatorWindow.uss`**：仅 `var(--kb-*)` token，复用 `CommonWindowStyles.uss` 既有类，仅新增双栏布局/分组树少量类

### 三、测试与文档

7. 文档同步：框架包 `README.md`、框架包 `CHANGELOG.md`、根 `AGENTS.md`（Editor 层 Window/ 清单 + CustomAttribute 内容清单补 CreatorEntry）
